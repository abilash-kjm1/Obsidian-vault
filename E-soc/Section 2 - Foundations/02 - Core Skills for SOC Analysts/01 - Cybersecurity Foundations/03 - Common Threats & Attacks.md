# 🛡️ CYBERSECURITY NOTES: THREATS, ATTACKS & COMMON EXPLOITS

---

# 1. THREAT, VULNERABILITY, ATTACK & RISK (CORE FOUNDATION)

```text
THREAT  →  VULNERABILITY  →  ATTACK  →  IMPACT (CIA LOSS)
```

### 📌 Threat

Any circumstance or event that has the potential to compromise:

- Confidentiality
    
- Integrity
    
- Availability
    

---

### 📌 Vulnerability

A weakness in:

- Hardware
    
- Software
    
- Process
    
- Human behavior
    

---

### 📌 Attack

An **intentional attempt** to exploit a vulnerability in order to:

- Steal data
    
- Disrupt services
    
- Gain unauthorized access
    
- Damage systems
    

---

### 📌 Risk

The **likelihood** that a threat will exploit a vulnerability and cause damage.

---

# 2. RELATIONSHIP FLOW (VERY IMPORTANT)

```text
Threat Actor
     │
     ▼
Identifies Vulnerability
     │
     ▼
Launches Attack
     │
     ▼
Exploits System
     │
     ▼
Causes Risk → Security Breach (CIA affected)
```

---

# 3. THREAT ACTORS (WHO PERFORMS ATTACKS)

|Threat Actor|Description|
|---|---|
|**Nation-State (APT)**|Government-backed, highly skilled attackers|
|**Script Kiddies**|Unskilled users using ready-made tools|
|**Hacktivists**|Politically or socially motivated attackers|
|**Insider Threats**|Employees or trusted users causing harm (intentional or accidental)|
|**Organized Crime**|Financially motivated cybercriminal groups|
|**Shadow IT**|Unauthorized systems/apps used without approval|

---

# 4. TYPES OF ATTACKS (WHAT THEY DO)

---

## A. MALWARE ATTACKS

```text
Malware = Malicious Software
```

|Attack|Description|
|---|---|
|Virus|Attaches to program and spreads when executed|
|Worm|Self-replicates across networks|
|Trojan|Appears legitimate but is malicious|
|RAT|Remote control of system|
|Ransomware|Encrypts data and demands payment|
|Spyware|Secretly monitors user activity|
|Keylogger|Records keystrokes|
|Rootkit|Hides malicious processes with admin access|
|Logic Bomb|Triggers on specific condition/event|

---

## B. SOCIAL ENGINEERING ATTACKS (HUMAN TARGET)

```text
Focus = Manipulating people
```

|Attack|Description|
|---|---|
|Phishing|Fake emails to steal data|
|Spear Phishing|Targeted phishing attack|
|Whaling|Targets executives|
|Vishing|Voice/phone-based phishing|
|Smishing|SMS-based phishing|
|Pretexting|Fake story to trick victim|
|Watering Hole|Infecting frequently visited websites|
|Tailgating|Following into restricted area|
|Typosquatting|Fake domains similar to real ones|

---

## C. NETWORK & APPLICATION ATTACKS

```text
Focus = Systems, networks, web apps
```

|Attack|Description|
|---|---|
|DoS|Single source service disruption|
|DDoS|Multiple systems overload target|
|SQL Injection|Manipulates database queries|
|XSS|Injects scripts into web pages|
|Buffer Overflow|Overloads memory to execute code|
|On-Path Attack|Intercepts communication|
|DNS Poisoning|Corrupts DNS records|
|Pharming|Redirects users to fake websites|
|Replay Attack|Reuses captured data/session|
|Directory Traversal|Accesses restricted files using `../`|

---

## D. WIRELESS & MOBILE ATTACKS

|Attack|Description|
|---|---|
|Evil Twin|Fake Wi-Fi network|
|Jamming|Blocks wireless signals|
|Bluejacking|Sends unwanted Bluetooth messages|
|Bluesnarfing|Steals Bluetooth data|
|Card Skimming|Captures card data at POS|
|Card Cloning|Duplicates stolen card data|

---


# 🎯 ONE-LINE MEMORY

> **Threat is danger, vulnerability is weakness, attack is exploitation, and risk is the chance of damage.**
