# How to Take Notes

[🏠 Dashboard](CCNA%20Dashboard.md) · [🗺️ Roadmap](Course%20Roadmap.md)

A short routine so the notes help you learn instead of becoming a second job.

## Each Study Session

**Before you press play**

1. Open the current day from **Continue here** on the Dashboard.
2. In the note's properties, set `status` to `In Progress` and `date_started` to today (YYYY-MM-DD).

**While watching**

- Use the **Watch on YouTube** link in each video's section, in the order listed.
- Write in **My Notes** in your own words. Pause the video to write; don't transcribe.
- Key terms go in **Important Concepts**; topologies, tables and packet flows go in **Examples and Diagrams**.
- Confused? Add it to **Questions I Have** straight away, with the video timestamp.
- Tick **Watched** and **Notes completed** as you go.

**Labs**

- Do each step yourself in Packet Tracer rather than only watching.
- Put what you actually typed under **Commands and Steps** (in a code block) and what happened under **Results**.
- Anything that broke, and how you fixed it, goes under **Problems and Solutions**.

**Flashcard videos**

- Tick **Completed** and list the cards you keep missing.

**After the day's videos**

1. Fill in **Day Summary** without looking at the video.
2. Write three self-test questions; answer them the next day.
3. Copy anything still unclear to [Unresolved Questions](../04%20-%20Questions%20and%20Doubts/Unresolved%20Questions.md).
4. Add commands you used to [Command Reference](../03%20-%20Cisco%20Commands/Command%20Reference.md).
5. Set `status` to `Done`, fill `date_completed`, tick the day on the Dashboard and point **Continue here** at the next day.

## Reviewing

- Use the **Review Checklist** at the bottom of each day note.
- Track weak topics and review sessions on the [Revision Dashboard](../05%20-%20Revision/Revision%20Dashboard.md).
- Log subnetting drills in [Subnetting Practice](../05%20-%20Revision/Subnetting%20Practice.md) and exam-style questions in [Question Bank](../06%20-%20Practice%20Questions/Question%20Bank.md).

## When to Make a Separate Note

Keep each day's notes together. Split something out only when it earns its own note:

| When | Template |
|---|---|
| A concept that spans several days | [Concept Note](../99%20-%20Templates/Concept%20Note.md) |
| A command you keep looking up | [Command Note](../99%20-%20Templates/Command%20Note.md) |
| A lab that needs more room than the day note | [Lab Note](../99%20-%20Templates/Lab%20Note.md) |
| A question that needs a longer answer | [Question Template](../04%20-%20Questions%20and%20Doubts/Question%20Template.md) |
| A practice question you got wrong | [Practice Question Template](../06%20-%20Practice%20Questions/Practice%20Question%20Template.md) |

To use a template, copy the file, rename it and keep it inside the `CCNA` folder (for example, make a `Concepts` folder when you write your first concept note).

Optional: in **Settings → Templates**, set the template folder location to `CCNA/99 - Templates`. Then the **Templates: Insert template** command fills a new note for you.
