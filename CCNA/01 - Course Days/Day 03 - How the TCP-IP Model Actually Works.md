

## Protocols

-  Set of rules defining how data should be communicated between devices over a network
- Basically its a **Language** computer use to communicate 


## Standard

- In old days each vendors [ IBM , apple etc ] develop their own protocols
- so its difficult to communicate with other devices
  
	![](Attachments/Day%2003%20-%20How%20the%20TCP-IP%20Model%20Actually%20Works.png)

> Standard is an agreed upon specification that describes how a protocol or technology should work 
> With vendor neutral standards, devices of all types can communicate with each other
> Ex : Apple mac can access the website hosted on the linux
